Paquetes importantes:

Para la camara: sudo apt install -y python3-picamera2
OpenCV: sudo apt install python3-opencv

Convertir imagenes en otros formatos a jpg:

Comando instalación: sudo apt install imagemagick

convert static/faces/5.jpg static/faces/5.jpg

Comparar 2 imagenes (test_facial_compare):

python test_facial_compare.py static/faces/yo1.jpg static/faces/yo_normal.jpg

Foto rápida con 5s de preview:

rpicam-still -t 5000 -o foto_prueba.jpg
